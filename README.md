# VeriFact AI
### An Explainable, Evidence-Grounded and Adaptive Hallucination Detection Framework for Large Language Models

## 1. Project Overview

VeriFact AI is a framework designed to identify and analyze potentially hallucinated information in responses generated by Large Language Models (LLMs).

The system aims to improve the reliability and transparency of LLM-generated answers by combining:

- Multiple response generation.
- Claim-level factual analysis.
- Self-consistency-based hallucination detection.
- External evidence retrieval and verification.
- Natural Language Inference (NLI).
- Explainable verification results.
- Adaptive verification to reduce unnecessary computational costs.

The project builds upon the ideas introduced in **SelfCheckGPT (Manakul et al., EMNLP 2023)** and extends the workflow through evidence-based verification, claim-level explanations, and adaptive processing.

**Important:** Consistency between generated answers does not guarantee factual correctness. A claim repeated consistently can still be false. Therefore, consistency analysis and external evidence verification are treated as separate components.

---

## 2. Project Objectives

1. Generate an original LLM response for a user-provided question.
2. Generate multiple independent responses to the same question.
3. Extract atomic factual claims from generated answers.
4. Identify inconsistencies between independently generated responses.
5. Retrieve relevant external evidence for claims.
6. Classify claims as Supported, Refuted, or Not Enough Information.
7. Provide understandable explanations for verification results.
8. Develop an interactive dashboard to display claim-level analysis.
9. Explore adaptive verification to balance accuracy and computational cost.

## Phase 1: Gemini API Integration and Original Response Generation

<ins>Status: Completed</ins>

### Objective

Establish communication between VeriFact AI and the Gemini API and implement the initial response-generation pipeline.

### 1. Gemini Client — `generation/llm_client.py`

Implemented a `GeminiClient` class responsible for communicating with Google's Gemini API.

Main responsibilities:

- Load API credentials from environment variables.
- Initialize the Gemini API client.
- Accept a text prompt.
- Send the prompt to the selected Gemini model.
- Retrieve the generated response.
- Validate that the prompt is not empty.
- Handle API errors.
- Check whether the generated response is empty.

Selected model:

```python
MODEL_NAME = "gemini-3.8-flash"
```

### 2. Original Response Generator — `generation/response_generator.py`

Implemented a `ResponseGenerator` class to generate the original answer for a user's question.

Main responsibilities:

- Accept a user question.
- Validate the input.
- Call the Gemini client.
- Generate the original answer.
- Return the result in a structured Python dictionary.

Example output structure:

```python
{
    "question": "Who discovered penicillin?",
    "answer": "Penicillin was discovered by Alexander Fleming...",
    "model": "gemini-3.8-flash"
}
```

### 3. Main Application — `main.py`

Implemented the initial command-line interface for VeriFact AI.

Main responsibilities:

- Display the application welcome message.
- Accept a question from the user.
- Initialize the response generator.
- Generate the original answer.
- Display the answer and generation details.
- Handle invalid input and API errors.

# 8. How to Run the Project

### Step 1: Clone or open the project

Open the project directory in Visual Studio Code.

### Step 2: Activate the virtual environment

On Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

### Step 3: Install dependencies (if setting up a fresh environment)

```powershell
pip install -r requirements.txt
```

### Step 4: Configure the API key

Create a `.env` file in the project root and add:

```env
GEMINI_API_KEY=your_actual_api_key
```

### Step 5: Run the application

```powershell
python main.py
```

Enter a question when prompted to receive an LLM-generated answer.
